# Development guidance

Keep this starter simple and understandable.

- Use plain HTML, CSS and JavaScript.
- Avoid frameworks, dependencies and build tools unless a specific feature requires them.
- Use small, clearly named functions instead of classes.
- Comment behaviour that is not obvious from the code.
- Request Chrome permissions only when necessary.
- Do not insert untrusted content with `innerHTML`. Use `textContent`.
- Update the README when behaviour or installation changes.
- Test the extension in Chrome after changes.
- Make small, descriptive Git commits.
